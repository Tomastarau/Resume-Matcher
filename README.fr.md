## Démarrage rapide

Resume Matcher fonctionne en créant un CV principal que vous pouvez utiliser pour adapter à chaque candidature. Instructions d'installation : [Comment installer](#comment-installer)

### Comment ça fonctionne

1. **Importez** votre CV principal (PDF ou DOCX)
2. **Collez** une description de poste ciblée
3. **Vérifiez** les améliorations générées par l'IA et le contenu adapté
4. **Lettre de motivation et e-mail** générés pour la candidature
5. **Personnalisez** la mise en page et les sections selon votre style
6. **Exportez** en PDF professionnel avec le modèle de votre choix

## Fonctionnalités principales

![resume_matcher_features](assets/features.png)

### Fonctionnalités de base

**CV Principal** : Créez un CV principal complet à partir de votre CV existant.

![Job Description Input](assets/step_2.png)

### Éditeur de CV

![Resume Builder](assets/step_5.png)

Collez une description de poste et obtenez un CV adapté par l'IA pour ce rôle spécifique.

Vous pouvez :

- Modifier le contenu suggéré
- Ajouter/supprimer des sections
- Réorganiser les sections par glisser-déposer
- Choisir parmi plusieurs modèles de CV

### Générateur de lettre de motivation et d'e-mail

Générez des lettres de motivation et des modèles d'e-mail adaptés basés sur la description de poste et votre CV.

![Cover Letter](assets/cover_letter.png)

### Score de CV (fonctionnalité en développement)

Nous travaillons sur une fonctionnalité de score de CV qui analysera votre CV par rapport à la description de poste et fournira un score de correspondance ainsi que des suggestions d'amélioration.

![Resume Scoring and Keyword Highlight](assets/keyword_highlighter.png)

### Export PDF

Exportez votre CV adapté et votre lettre de motivation en PDF.

## Comment installer

![Installation](assets/how_to_install_resumematcher.png)

Pour des instructions détaillées, consultez **[SETUP.md](SETUP.md)** (anglais).

### Prérequis

| Outil | Version | Installation |
|-------|---------|--------------|
| Python | 3.13+ | [python.org](https://python.org) |
| Node.js | 22+ | [nodejs.org](https://nodejs.org) |
| uv | Dernière | [astral.sh/uv](https://docs.astral.sh/uv/getting-started/installation/) |

### Démarrage rapide

Recommandé pour MacOS, WSL et Ubuntu :

```bash
# Cloner le dépôt
git clone https://github.com/srbhr/Resume-Matcher.git
cd Resume-Matcher

# Backend (Terminal 1)
cd apps/backend
cp .env.example .env        # Configurez votre fournisseur IA
uv sync                      # Installez les dépendances
uv run uvicorn app.main:app --reload --port 8000

# Frontend (Terminal 2)
cd apps/frontend
npm install
npm run dev
```

Ouvrez **<http://localhost:3000>** et configurez votre fournisseur IA dans les Paramètres.

### Fournisseurs IA supportés

| Fournisseur | Local/Cloud | Notes |
|-------------|-------------|-------|
| **Ollama** | Local | Gratuit, fonctionne sur votre machine |
| **OpenAI** | Cloud | GPT-4o, GPT-4o-mini |
| **Anthropic** | Cloud | Claude 3.5 Sonnet |
| **Google Gemini** | Cloud | Gemini 1.5 Flash/Pro |
| **OpenRouter** | Cloud | Accès à plusieurs modèles |
| **DeepSeek** | Cloud | DeepSeek Chat |

### Déploiement Docker

Les images Docker officielles sont publiées pour `linux/amd64` et `linux/arm64` sur :

- `ghcr.io/srbhr/resume-matcher`
- `srbhr/resume-matcher`

Lancez sur un port public unique (`3000`) avec l'API disponible sur `/api` :

```bash
docker run --name resume-matcher \
  -p 3000:3000 \
  -v resume-data:/app/backend/data \
  ghcr.io/srbhr/resume-matcher:latest
```

Préférez épingler une version en production, par exemple `ghcr.io/srbhr/resume-matcher:1.1.0`.

Points d'accès :

- Application : <http://localhost:3000>
- Vérification de santé API : <http://localhost:3000/api/v1/health>
- Documentation API : <http://localhost:3000/docs>

> **Utilisation d'Ollama avec Docker ?** Utilisez `http://host.docker.internal:11434` comme URL Ollama au lieu de `localhost`.

### Stack technique

| Composant | Technologie |
|-----------|-------------|
| Backend | FastAPI, Python 3.13+, LiteLLM |
| Frontend | Next.js 15, React 19, TypeScript |
| Base de données | TinyDB (stockage fichier JSON) |
| Style | Tailwind CSS 4, Style International Suisse |
| PDF | Chromium headless via Playwright |
